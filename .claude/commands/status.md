사이트의 현재 상태를 요약한다. 파일을 바꾸지 않는다.

1. `npm run status`를 실행한다 (기준 시각은 지금. 다른 날짜로 보고 싶으면 입력값 "$ARGUMENTS"가 날짜일 때 `PYEJI_NOW`로 넘긴다).
2. 출력 중 "docs/questions.md의 확인 필요·제안 항목"은 이미 해결된 것이 섞여 있다. 같은 문서의 뒤쪽 기록이나 현재 데이터·글과 대조해서 해결된 것은 빼고, 아직 열린 것만 남긴다 (해결 근거를 한 줄로).
3. 보고 순서 (한국 시간, 짧게)
   - 앞으로 2주: 시즌 시작·종료, 이벤트
   - 시각 발표를 기다리는 것: 언제쯤 발표될지 공식 공지에 나와 있으면 그것만
   - 공식 확인이 덜 된 값
   - drafts/에 남은 초안: 공개 대기인지, 참고용인지
   - 열린 질문: 운영자가 정해야 하는 것만
   - 다음에 쓸 명령 제안 (예: "3.30 시각이 나오면 /new-season {링크}")
