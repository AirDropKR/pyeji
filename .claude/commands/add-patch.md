패치노트 링크를 사이트의 리그별 패치 목록에 추가한다. 입력: $ARGUMENTS

먼저 `docs/ops-common.md`의 공통 절차를 읽고 따른다 (CLAUDE.md 규칙 포함).

1. 링크가 공식 출처인지 확인한다. 아니면 멈춘다.
2. 링크에서 게임, 버전(예: "3.29.1 패치", "3.29.1c 핫픽스"), 게시 시각만 확인한다. 패치 내용은 읽어도 옮기거나 요약하지 않는다.
3. 연결 시즌: 그 패치가 나온 시점에 진행 중이던 시즌 (`src/data/seasons.json`의 시작·종료로 판단).
4. `src/data/patches.json`에 기존 항목 모양 그대로 추가한다.
   - `id`: `{게임}-{공지 번호}` (예: poe1-4012345), 공지 번호가 없으면 `{게임}-{버전}`
   - `kind`: 핫픽스면 `hotfix`, 아니면 `patch`
   - `kakaoUrl`: 카카오게임즈 패치노트 링크가 입력에 있으면
   - `note`: 넣지 않는다 (운영자가 직접 쓸 때만)
   - 같은 `sourceUrl`이 이미 있으면 추가하지 않고 "바뀔 것 없음"
5. 공통 절차의 "끝낼 때"를 따른다. 커밋 예: `data: 3.29.2 패치 링크 추가 (/add-patch)`
