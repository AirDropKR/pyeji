기존 게시글에 새로 나온 공식 정보를 반영한다. 입력: $ARGUMENTS

먼저 `docs/ops-common.md`의 공통 절차를 읽고 따른다 (CLAUDE.md 규칙 포함).

1. 첫 번째 입력으로 글을 찾는다. `https://pyeji.kr/posts/poe1/3-30-preview/`, `/posts/poe1/3-30-preview/`, `poe1/3-30-preview` 모두 `src/content/posts/poe1/3-30-preview.md`. 없으면 멈춘다.
2. 나머지 링크가 공식 출처인지 확인한다. 아니면 멈춘다.
3. 링크에서 글 주제와 관계있는 새 사실만 뽑는다. 글에 이미 같은 내용이 있으면 "바뀔 것 없음"으로 끝낸다.
4. 반영 방법
   - 새 사실은 글 주제에 맞는 기존 소제목 안에 직접 쓴 문장으로 넣는다. 맞는 소제목이 없으면 주제·질문형 소제목을 새로 만든다 (고정 소제목 금지)
   - 이제 틀리게 된 문장(예: "아직 발표되지 않았다")은 고친다
   - 첫 문단의 핵심 답이 바뀌었으면 첫 문단도 고친다. 제목·description이 사실과 어긋나면 고친다
   - 새 링크는 frontmatter `sourceUrls`에 추가
   - 맨 아래 "## 업데이트"의 맨 위에 `- {M}월 {D}일: {무엇을 반영했는지 한 줄}` 추가 (오늘 한국 날짜)
5. 확인: 빌드 후 `dist/posts/{slug}/index.html`의 갱신일이 오늘로 바뀌었는지 본다 (수정일은 업데이트 기록 첫 줄에서 자동으로 계산된다)
6. 사실 문장을 3개 이상 새로 썼으면 `/fact-check {slug}`를 실행하라고 보고에 적는다.
7. 공통 절차의 "끝낼 때"를 따른다. 커밋 예: `data: 3.30 리그 이름 반영 (/update-post)`
