argument-hint: <공식 링크> [연결할 시즌 id]

---
시즌 전후 일정(공개 방송, PTR, 사전 다운로드, 이벤트 리그, 시즌 종료 공지 등)을 반영한다. 입력: $ARGUMENTS

먼저 `docs/ops-common.md`의 공통 절차를 읽고 따른다 (CLAUDE.md 규칙 포함).

1. 링크가 공식 출처인지 확인한다. 아니면 멈춘다.
2. 링크에서 일정 이름, 시작 시각(있으면 끝 시각), 게임을 찾는다. 시각이 없으면 `timePrecision: "day"`.
3. 연결 시즌: 입력에 시즌 id가 있으면 그것, 없으면 그 일정이 어느 시즌에 관한 것인지 링크 내용으로 정한다(예: 3.30 공개 방송 → poe1-3-30). 판단이 안 되면 연결하지 않고 보고에 적는다.
4. `src/data/events.json`에 기존 항목 모양 그대로 추가한다.
   - `id`: `{게임}-{시즌 또는 버전}-{종류}` (예: d4-s16-ptr, poe1-3-31-reveal)
   - `title`: 화면에 그대로 나가는 짧은 명사형 (예: "16시즌 공개 테스트 서버", "3.31 공개 방송")
   - 같은 행사를 여러 항목으로 나누지 않는다 (예: 같은 행사의 생중계와 키노트는 하나로)
   - 이미 같은 일정이 있으면 바뀐 값만 고친다
5. 연결 시즌 페이지의 주요 일정 띠, 메인·/now/, 월간 글 카운트다운에 자동으로 들어가는지 빌드 결과에서 확인한다.
6. 공통 절차의 "끝낼 때"를 따른다. 커밋 예: `data: 16시즌 공개 테스트 서버 일정 추가 (/new-event)`
