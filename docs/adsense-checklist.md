## 검토 기간 동안 (운영자 안내 기준)
- 기존 페이지 삭제·주소 변경, 광고 단위 추가, 사이트 접근을 막는 설정 변경은 하지 않음
- 글과 기능 추가는 괜찮음. 2차 작업 1~5와 3차 작업 1~7은 모두 주소를 바꾸지 않고 추가·수정만 함
- 끝난 시즌 페이지가 날짜에 따라 noindex로 바뀌는 것은 주소 삭제가 아니라 기존 규칙 그대로

## 승인 후 (별도 작업)
- 광고 단위 코드 받기 → 위치: 메인 하단, 게시글 본문 중간, 넓은 화면 사이드
- D-day 도장과 카운트다운 바로 옆에는 두지 않음
- 광고 영역 높이를 고정해 화면이 밀리지 않게
