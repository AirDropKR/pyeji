# 콘텐츠 점검표 (7차 작업 1, 2026-10-31 빌드 기준)

애드센스 첫 검토 결과 "가치가 별로 없는 콘텐츠"로 거절된 뒤 검색 노출 페이지 전부를 점검한 표. 다시 재려면 `npm run build` 후 `node scripts/content-audit.mjs`.

## 재는 방법
- **직접 쓴 본문**: 공백을 뺀 글자 수. 데이터에서 자동으로 만든 표·목록·링크·날짜는 세지 않는다
  - 글: 마크다운 원문에서 표·제목·이미지·"## 업데이트" 이후·링크만 있는 줄을 뺀 문장
  - 안내 페이지: 제목을 뺀 본문 전체 (목록도 직접 쓴 글)
  - 그 밖의 페이지: 화면에서 표·목록·정의 목록·제목·링크를 뺀 문단. "한국 시간 … 시작"처럼 템플릿이 데이터로 채운 문장도 여기에 들어가므로 실제 직접 쓴 양은 이보다 적다
- **화면 전체**: 본문(`<main>`) 글자 수. 자동 생성 표·목록 포함
- **겹침**: 본문의 문단·목록·표 칸(10자 이상) 중 다른 페이지에도 똑같이 있는 글의 비율. 글끼리 틀이 비슷한 것(문장 구조가 같은 것)은 이 숫자에 안 잡혀 "비고"에 따로 적었다

| 보강 | 검색 수요가 있는 페이지(진행 중·다음 시즌, 게임별 일정)인데 직접 쓴 설명이 100자 미만이거나, 글인데 400자 미만 |
| 검색 제외 후보 | 직접 쓴 설명이 거의 없고(100자 미만) 겹침 80% 이상이며, 같은 검색어를 다른 페이지가 이미 맡는 페이지 |
