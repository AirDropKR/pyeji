## 작업 1. 모바일 게시글 표 넘침

결정한 것
- 원인: 마크다운 표가 감싸개 없이 출력되고 전역 `table`에 `min-width: 480px`가 걸려 있었음
- 처음 계획한 빌드 단계 처리(rehype 플러그인)는 Astro 7 기본 마크다운 처리기에서 `@astrojs/markdown-remark` 설치가 필요해서 포기 (새 의존성 회피)
- 대신 CSS 기본 처리 + 브라우저 보강
  - CSS: 게시글 표 자체를 가로 스크롤 상자로 (JS가 없어도 본문 밖으로 넘치지 않음)
  - `live.ts`: 표를 `.tbl` 감싸개로 옮기고 칸마다 머리글 이름표(`data-label`)를 붙임
- 비교 결과 칸 3개 이하 표는 560px 이하에서 행마다 세로로 쌓는 쪽이 가로 스크롤보다 읽기 쉬워서 채택 ("한국 시간 · 11월 7일(토) 오전 5시"처럼 칸 이름이 앞에 붙음). 칸 4개 이상 표는 가로 스크롤
- 게시글 3개를 390px 폭에서 확인 (Edge 헤드리스 + 390px iframe)

확인이 필요한 것
- 세로로 쌓는 방식이 마음에 들지 않으면 `.stack` 규칙만 지우면 가로 스크롤로 돌아감
