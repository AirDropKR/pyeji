## 바꾼 것

### 1. 대표 주소 (작업 1)
- 코드·데이터·글·결과물에 www.pyeji.kr이나 http://pyeji.kr이 하드코딩된 곳 없음. canonical, og:url, og:image, 사이트맵, RSS, 구조화 데이터(url), robots.txt Sitemap 줄 모두 https://pyeji.kr (빌드 결과물 321곳 확인). manifest는 상대 주소(/now/)
- `npm run check:site`에 "대표 주소가 아닌 주소" 검사 추가
- 10월 31일 실서버 확인: www·http 모두 이미 https://pyeji.kr로 301. 다만 `http://www.pyeji.kr/` → `https://www.pyeji.kr/` → `https://pyeji.kr/` 두 번 이동
- 구글이 www를 고른 이유는 코드에서는 찾지 못함. 짐작되는 것: 리다이렉트가 생기기 전 www도 200으로 같은 내용을 보여 줬거나, 외부 링크·서치 콘솔 등록·처음 공유한 주소가 www였던 경우. 리다이렉트가 유지되면 구글이 다시 크롤링하면서 https://pyeji.kr로 옮겨 간다
